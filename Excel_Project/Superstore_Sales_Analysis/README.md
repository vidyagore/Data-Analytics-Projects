# Superstore Sales Analysis (Excel)

## Overview
Excel dashboard created to analyze Superstore sales data.
It focuses on sales performance, regional trends, and customer segments.

## Key Insights
- Overall sales and average sales trend
- Region-wise performance comparison
- Category-wise and sub-category analysis
- Monthly quantity ordered trends
- Customer segment contribution to total sales

## Folder Structure
- Raw_Data: Contains the original dataset
- Dashboard: Contains the Excel dashboard and screenshot
