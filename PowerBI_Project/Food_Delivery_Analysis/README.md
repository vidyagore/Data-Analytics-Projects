# Food Delivery Analysis (Power BI)

## Project Description
This Power BI project analyzes food delivery operations using interactive dashboards.
The analysis covers total orders, customers, revenue, delivery time, order status,
payment modes, meal-time patterns, and delivery partner performance.

The project includes data cleaning and transformation using Power Query,
data modeling with relationships, and DAX measures to calculate KPIs.
Interactive slicers and visuals are used to explore trends, comparisons,
and performance insights for better decision-making.

## Key Insights
- Overall view of total orders, customers, revenue, and menu count
- Order status analysis (Delivered, Cancelled, Pending, Returned)
- Orders distribution by meal time (Morning, Afternoon, Evening, Night)
- Delivery partner-wise order contribution
- Monthly and day-wise revenue trends
- Delivery time analysis by time categories
- Payment mode comparison (COD, Online, Wallet)

## Folder Structure
- Raw_Data: Contains the original food delivery dataset
- Dashboard: Contains the Power BI dashboard (.pbix) file and screenshot
