# Real Estate Analytics Dashboard (Power BI)

## 📌 Project Overview
This project is a **Power BI dashboard** created to analyze and visualize key metrics
for a **sample real estate builder named "Shivshakti Builders"**.

The objective of this project is to simulate **real-world business reporting**
and demonstrate skills in **data modeling, DAX, and dashboard design**.

---

## 📊 Dashboard Structure

### 1️⃣ Project Portfolio Overview
- Total projects and total units
- Project-wise sales amount, project cost, and loan amount
- Project approval and compliance status
- High-level portfolio insights for management

### 2️⃣ Sales Performance Overview
- Monthly sales trend (sold flats only)
- Project-wise sales amount (realized revenue)
- Payment mode analysis (Cheque / NEFT / RTGS)
- Booked amount calculated at **10% advance value**

### 3️⃣ Flats & Selling Value Overview
- Flats distribution by status (Sold / Booked / Unsold)
- Flat type analysis (1BHK / 2BHK / Studio)
- Selling value based on listed flat prices
- Average selling price per unit

### 4️⃣ Cost & Loans Overview
- Category-wise project cost breakup
- Project-wise loan amount and outstanding balance
- Loan repaid vs loan balance analysis
- Bank-wise loan filtering
