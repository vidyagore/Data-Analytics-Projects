# Retail Sales Dashboard (Power BI)

## Project Description
This Power BI project analyzes retail sales data using multiple datasets,
including customer, product, sales, and store information.
The data is combined and modeled to create interactive dashboards
that provide insights into sales performance and business trends.

The project involves data cleaning and transformation using Power Query,
data modeling across multiple tables, and DAX calculations for KPIs.
The dashboard helps analyze sales trends, category performance,
store-wise performance, and customer behavior.

## Key Insights
- Overall sales and revenue performance
- Category-wise and product-wise sales analysis
- Store-wise sales comparison
- Customer-level insights and buying patterns
- Sales trends over time

## Folder Details
- Raw_Data: Contains source datasets such as Customer, Product, Sales, and Store files
- Dashboard: Contains the Power BI dashboard (.pbix) file and dashboard screenshot
